Submit a new antenna

Enter the public specs, generate the JSON, then open a prefilled GitHub issue. Cite the vendor datasheet. The form covers the catalog fields only.

Step 1: Fill in the form and click “Generate JSON Snippet”. Step 2: Click “Open GitHub Issue with This Entry” and submit the prefilled issue on GitHub. You can drag image files onto the GitHub issue after it opens.

Workflow: generate the JSON, open the prefilled GitHub issue, then review and submit it. A maintainer labels the issue antenna-submission and automation opens the pull request.
